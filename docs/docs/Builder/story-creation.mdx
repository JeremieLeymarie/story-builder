# Index

![logo](/img/builder_home.jpg)

This is the story builder engine that boasts powerful narrative options for your stories.

To create your first story in Story Builder you need first to head to the "Builder" section which contains the engine that allow you to freely create stories.

This the page where all the stories you are currently creating are stored. You can choose any story you wish to modify or you can create new stories thanks to the "Build you own stories" button.

You can also import stories in a JSON format and then continue building your stories or work on those of your friends and relatives !

For the sake of this presentation, we are going to chose a story and see how things unfold in the most crucial part of Story Builder : THE BUILDER !
