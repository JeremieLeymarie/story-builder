# Conditional actions

Until now we have seen how we can create a story through scene creation and connection. Now we will delve further into the possibilities available to the creator to make his story more dynamic.

Conditional actions is a tool available to the user on the action scene creation pannel.

Here we take the same story pather as in the last chapter and we create additional scenes to further enrich the story :

<img src="/img/builder_conditional_actions.png" alt="builder scene actions" width="700" />

Now that we have a more furnished story path we can see that the each scene has two actions that develop the story further. It is important to note that you can create more actions
you are not limited to 2.

The functionnality i would like you to focus on here is linked to the little gear logo you have next to an action on the action tab of the scene creation panel.
