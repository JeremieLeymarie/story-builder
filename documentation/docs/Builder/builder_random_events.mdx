# Random Events

Random Events is a particular functionnality available to you in the builder section.
Similarly to conditional actions, random events are created to dyanmize the story further and make it more alive.

The way is works is actually very simple, you just need to draw two new scenes from the same scene endpoint as pictured in the image below :

<img src="/img/builder_random_events.png" alt="builder conditionals" width="700" />

Here we have drawn to paths from the same action endpoint which results in the creation of a conditional action.
The way it workd is quite simple all you have to do is fill the percentage of "chance" that the player will have of accessing a given scene.

For example let's say that i create those 2 new scenes and i give them the name "eight scene" and "ninth scene" and that when i choose the seventh action of my fourth scene i want 70%
chance of reaching the eight scene and 30% chance of reaching the ninth scene.

<img src="/img/builder_random_events_settings.png" alt="builder conditionals settings" width="700" />

The choice will now be set by the user to the player of the story because each time the seventh action gets picked, the player has a 70% of accessing the eight scene against 30% for the ninth scene.
This feature further improves the replayability of the story and even displays "secret scenes" kind of vibe if you set the percentage to very low numbers like 1 or 5.

This percentage will by design not be shown to the player.

The choice is of course not limited to 2 branches as displayed in the example above. You can draw multiple branches from the same action endpoint the important point to remember is that the
total percentage of those branches has to be 100%.
