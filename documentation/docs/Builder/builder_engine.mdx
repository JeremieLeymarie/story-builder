
# Builder engine

You can here create any story you want by using the various features available to you.

This is the first thing you see when you click on the "save" button in the form.

<img src="/img/builder_engine.png" alt="logo" width="1000" />

You can see the first scene from which your story will take roots.

You need to double click on the first scene card right in the middle so you can initialize your first scene.

Once you have a double clicked on it, a popup window will appear

<img src="/img/builder_first_scene.png" alt="logo" width="1000" />

This "Edit scene" popup contains 2 main tabs named Scene and Actions. You need next to type a title and a description for your story.

This is what you get once you have filled out all the necessary information:

<img src="/img/builder_first_scene2.png" alt="logo" width="1000" />

Rich text is available to you in the description field. As you can see i used bold and itallic for my description text. You can access the "Actions" tab by clicking on it

To create a new scene linked to one of the two actions you have to click on the black dot next to the chosen action.

<img src="/img/builder_new_scene.png" alt="logo" width="400" />

From then you just have to fill the scene like we just did to create your second scene.

This is the very essence of Story Builder! Connecting various scenes together to create dynamic stories that are connected to each other.
This allows you to create stories with multiple possibilities.
