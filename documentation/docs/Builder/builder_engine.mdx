
# Builder engine

You can here create any story you want by using the various features available to you.

This is the first thing you see when you click on the "save" button in the form.

<img src="/img/builder_engine.png" alt="logo" width="1000" />

You can see the first scene from which your story will take roots.

You need to double click on the first scene card right in the middle so you can initialize your first scene.

Once you have a double clicked on it, a popup window will appear

<img src="/img/builder_first_scene.png" alt="logo" width="1000" />

This "Edit scene" popup contains 2 main tabs named Scene and Actions. You need next to type a title and a description for your story.
