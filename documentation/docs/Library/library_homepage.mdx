# Homepage

This is where the games that you have created and imported are saved. You can access it by clicking the "Your games" button in the navbar.

<img src="/img/library_navbar_button.png" alt="library navbar button" width="1000" />

You then reach the home page of the library :

<img src="/img/library_homepage.png" alt="library homepage" width="800" />

You can see that it is currently empty, no stories of any kind.

To remediate this there is an "Import Your Game" option available to you, with that you can import all the stories created in Story Builder: The ones you have created yourself
and other people's creations.
There is however a constraint for this import function : JSON only.
All the stories that you import or export within Story Builder are in JSON format, which is a standard text-based format that allows us to easily share stories between different users.

Here if you click the "Import from JSON" button, a popup window appears :

<img src="/img/library_import_popup.png" alt="library import popup" width="400" />

All you have to do is drag and drop your story in JSON format or click on the window to browse the files in you computer and choose the story you want to import.

<img src="/img/library_explorer_import.png" alt="library explorer import" width="400" />


You can then access your story from the library now that it is imported.

<img src="/img/library_import_success.png" alt="library import success" width="800" />
